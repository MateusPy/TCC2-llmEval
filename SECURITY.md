# Política de Segurança

## Versões suportadas

O projeto está em desenvolvimento ativo. Correções de segurança são aplicadas
sobre a última versão publicada no PyPI.

| Versão | Suporte |
|---|---|
| 0.1.x | ✅ |
| < 0.1 | ❌ |

## Reportando uma vulnerabilidade

**Não abra uma issue pública** para falhas de segurança.

Use o canal privado do GitHub — **Private Vulnerability Reporting**:

1. Acesse a aba **Security** do repositório, ou vá direto em
   <https://github.com/MateusPy/TCC2-llmEval/security/advisories/new>.
2. Clique em **Report a vulnerability** e descreva o problema com o máximo de
   detalhe possível (passos para reproduzir, impacto, versão afetada).

Esse canal é privado entre você e os mantenedores; nenhum dado fica exposto
publicamente até que a correção seja coordenada.

> Se o Private Vulnerability Reporting não estiver habilitado, os mantenedores
> devem ativá-lo em **Settings → Code security and analysis → Private
> vulnerability reporting**.

## O que esperar

- **Confirmação de recebimento** assim que possível.
- **Avaliação** do impacto e da reprodutibilidade.
- **Correção coordenada**: trabalhamos numa correção e só divulgamos os detalhes
  depois que uma versão corrigida estiver disponível, creditando quem reportou
  (se desejar).

Obrigado por ajudar a manter o `llm-eval` seguro.
